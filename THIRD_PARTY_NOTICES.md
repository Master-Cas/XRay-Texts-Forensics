# Third-Party Notices

No third-party source code is vendored in M0.

The architecture has been informed by public research, documentation, and independently reviewed projects involving SynthID-Text, statistical watermark detection, watermark robustness, text forensics, corpus analysis, and digital-forensic evidence modelling.

Research influence does **not** imply code incorporation.

## Clean-room boundary

T-LAB was examined only to understand documented concepts, formats, dependencies, and published analytical methods. Its included EULA restricts reverse engineering/decompilation/disassembly. XRay must not copy T-LAB proprietary implementation. Any analogous capability must be independently implemented from public mathematical descriptions, literature, and independently written tests.

When third-party code is added later, record component/version, source, license, modification status, and required attribution/NOTICE text here.
